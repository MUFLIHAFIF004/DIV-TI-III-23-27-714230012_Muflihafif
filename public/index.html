Selamat Datang di Agentic Integration Testing QA Assistant!

Saya adalah asisten penguji integrasi API otomatis berbasis **Micro-Agentic Architecture** (Agent 1 Payload Generator, Agent 2 Async HTTP Runner, & Agent 3 Gemini LLM Evaluator).

📖 Tata Cara Penggunaan Sistem:

  1. Target Endpoint API: Masukkan URL API yang ingin kamu uji pada kolom input di bawah.
  2. Skenario Pengujian: Tuliskan deskripsi skenario pengujian (misal: uji payload valid, data besar, & payload invalid).
  3. Eksekusi: Klik tombol "🚀 Kirim Pengujian" untuk memicu eksekusi 3 Micro-Agents.
  4. Hasil & File Export:
    • Laporan evaluasi visual Markdown (MD) langsung dirender di obrolan chat.
    • Unduh file mentah JSON via tombol 📥 Download Output JSON.
    • Hasil pengujian otomatis tersimpan di folder lokal: app/output/raw_json/ dan app/output/reports/.
    • Riwayat tersimpan permanen di database MongoDB Atlas.
